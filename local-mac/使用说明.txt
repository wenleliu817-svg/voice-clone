有道声音复刻 · Mac 本地版

1. 将整个文件夹解压到桌面，不要只取出启动文件。
2. 双击“启动声音复刻.command”，浏览器会自动打开本机页面。
3. 填写自己的有道 AppID、App Secret，上传参考音频（建议 5–10 秒），输入文本，点击开始生成。
4. 生成后可播放和下载。使用期间保持终端窗口打开，结束时按 Control+C。

要求：macOS，Python 3.9 或以上（Intel / Apple 芯片均可）。不需要 Flask、Homebrew 或其他 Python 包。
如果启动提示未安装 Python，请从 https://www.python.org/downloads/macos/ 安装官方 macOS universal2 版本，再启动。
若双击提示没有执行权限，在终端输入 chmod +x 后拖入“启动声音复刻.command”，回车后再次双击。
若 macOS 显示来源安全提示，请按你所在组织的软件使用规则处理，不要关闭系统安全保护。

工作方式：只监听 127.0.0.1，本机页面连接本机代理，代理直接连接有道官方 API。
不依赖 GitHub Pages、Cloudflare workers.dev、Render，不需要开放任何入站端口。
用户的网络仍须能访问 openapi.youdao.com 及有道音频 CDN。调用会按有道平台规则计费。
App Secret 仅在当前页面参与签名，不保存在文件里，不发送给本机代理。参考音频、文本和签名会发给有道。
所有使用者均需自行开通“大模型声音复刻”和“大模型语音合成”，如应用设置 IP 白名单还需允许各自的网络出口 IP。
请勿将自己的 AppID、密钥或私人录音预填进分发包。

连接错误：先确认保持启动窗口打开，使用自动打开的 http://127.0.0.1:随机端口 页面，不要打开旧的 GitHub Pages 地址。
如果“检测连接”成功但合成失败，请根据页面返回的有道错误码检查余额、服务开通和网络。
